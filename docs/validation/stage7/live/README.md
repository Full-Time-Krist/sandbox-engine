## 1000 предметов

Подготовлены два мира с одинаковыми игроком, блоками, сидом и камерой. В benchmark — 1000 полных стопок дёрна на площадке 32×32, baseline — тот же мир без сущностей. Выбор полного размера стопок препятствует слиянию; творческий игрок не подбирает предметы. `baseline.png` и `1000-items.png` — настоящие кадры.

После загрузки 1639 чанков/213 мешей:

| Метрика | Без предметов | 1000 предметов, два интервала по 10 с |
|---|---|---|
| FPS / TPS | 60 / 20 | 60 / 20 |
| Видимые предметы |0|1000|
| Средний тик сервера |0,06 мс|0,88 /0,67 мс|
| Самый долгий кадр |18,4 мс|18,8 /18,6 мс|
| Кадры>20 мс |0|0 /0|
| CPU вызова ItemRenderer.Draw |0,0044 мс|0,1095 /0,1118 мс|
| Draw + glFinish |0,0128 мс|0,3776 /0,3770 мс|
| Максимум Draw + glFinish |0,0367 мс|0,8366 /0,8937 мс|

Логи `baseline.log` и `1000-items.log`. Первый 10 с интервал включает генерацию/JIT/подгрузку:2 медленныхкадра безпредметов,7 с 1000 предметами; для сравнения стабильной сцены он исключён. Временный `glFinish` перед замером отделял очередь GPU чанков, второй после Draw измерял завершение предметов. Эта синхронизация влияет на распараллеливание CPU/GPU, поэтому отдельно приведены CPU и Draw+Finish. Измерительный код после проверки полностью удалён.

Полёт этапа 6 и статическая площадка — разные сценарии; прямого сравнения стоимости тика нет. Бюджет 20TPS и стабильные 60FPS с 1000 видимымипредметами выдержаны.
